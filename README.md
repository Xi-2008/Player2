# Player2

Player2是一个Godot引擎写的跑酷与恐怖两个模式的游戏 
WASD 或方向键移动

> **未完成版本。** 当前是跑酷玩法，未来计划往恐怖方向演进，
> 但方向尚未定型，这里展示的是进行中的状态。

- 当前版本：`0.6.1`
- 两种模式：跑酷 与 （第一次）恐怖游戏
- 技术：Godot 3.5.2 · GDScript · 导出到 Web（HTML5 + WebAssembly）与 Windows

### 操作

- 移动：`W` `A` `S` `D` 或 方向键
- ESC：暂停并返回或退出
- 其余操作见游戏内
